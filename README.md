# Projeto Ideia

To use this project is needed to hava maven and java installed in your computer machine. This project was made in a windows operating system. 

Start the server : mvn spring-boot:run

Test the code: mvn test

Compile project: mvn clean compile


This is the project for a website where you can share and find ideas with other people, when you are on a Creativity Crises period you can use it to find so inspiration or if you are on a Creative Breakthrough you can get the opion of other people for it.
